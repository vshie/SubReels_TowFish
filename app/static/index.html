Mutually exclusive with video recording. Captures one JPEG every 500 ms from the camera's snapshot CGI and writes them to timelapse_<timestamp>/ with a telemetry.csv sidecar so each frame is geotaggable.

Transect Auto (mavlink-triggered .ts segments)

When enabled, the recorder polls the tow vehicle's mission state via mavlink2rest and produces one .ts file per waypoint leg. The RTSP pipeline stays alive across leg boundaries (rolled via splitmuxsink split-now at each MISSION_CURRENT.seq change), so the only "missing" footage is the few hundred ms the muxer needs to rotate at an IDR boundary. Per-leg metadata (start/end GPS, heading, wp_dist) is written to a sibling transect_<TS>_manifest.ndjson. Mutually exclusive with manual recording and timelapse.
